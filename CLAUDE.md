# Fantasy-FPL

Når Simen ber om FPL-analyse for en runde («Start FPL-analyse for runde N» eller lignende):
følg `samarbeid/RUTINE.md` fra start til slutt, sammen med Codex, uten å stoppe for spørsmål.
Gjør aldri endringer på FPL-kontoen.

Ukentlig analyse kjøres alltid fra `main`. Står repoet på en annen gren (f.eks. `modellforbedring`):
commit eller stash det som ligger der, og `git switch main` før rutinen starter. Status for modellarbeidet: `samarbeid/modell/STATUS.md`.
